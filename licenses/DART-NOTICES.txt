DartControl authors: Kaifeng Zhao, Gen Li and Siyu Tang (ICLR 2025).
The upstream Apache-2.0 license, including its original copyright statement,
is retained in DART-SOURCE.txt.

Native host transforms/sampler/policy orchestration and exported graph schemas
are adapted from model/mld_vae.py, model/mld_denoiser.py,
control/policy/policy.py, control/env/env_reach_location_mld.py,
mld/rollout_mld.py, utils/smpl_utils.py and diffusion/gaussian_diffusion.py.
Changes: native C++ host loop and model preparation; predicted-joint inference;
model-mean/generated warmup; normalizer-derived pelvis offset; generated fixed
reference skeleton; explicit SOMA mapping and fixed-length export; bounded plans.
The source attention/position modules retain the original notice:
Copyright (c) Facebook, Inc. and its affiliates. All Rights Reserved
They build on DETR/MLD/PyTorch (DETR: https://github.com/facebookresearch/detr,
Apache-2.0). DART's imported embeddings helper also credits SignJoey
(https://github.com/neccam/slt, Apache-2.0); the used timestep operations are
compiled into the native graphs, not a bundled Python package. Source copies
are pinned by the DART revision above. No upstream Python package,
training/evaluation code or body model is bundled in the executable.

OpenAI CLIP source and model: OpenAI/CLIP at
d05afc436d78f1c48dc0dbf8e5980a9d471f35f6, MIT (OPENAI-CLIP.txt).
The native text graph and fixed token sequences derive from that source and its
official ViT-B/32 checkpoint. Image inference is not used. Text model training
data is not distributed. Research deployment recommendations in the model card
are retained as upstream context and are not represented as an NC license.

DART's author expressly confirms code and checkpoints under Apache-2.0 at:
https://github.com/zkf1997/DART/issues/25#issuecomment-3806649923
The normalizer is used as part of the released inference model. External SMPL-X,
SMPL-H, AMASS, BABEL and HumanML3D assets are not bundled or downloaded by this
backend; their separate terms are not replaced by the DART grant. No parametric
body mesh, blendshape, evaluation motion or upstream stand.pkl is used.

Models remain external verified downloads. No checkpoint tensor data is included
in Git or runtime packages. src/generated/dart-graphs.inc contains operator/schema
definitions and external byte ranges only; all learned tensors reside in the
separately installed, content-pinned model files.
